# 界面语言

顶部语言菜单支持简体中文和 English，默认中文。偏好保存在当前浏览器/桌面 WebView 的 `rocos-locale`，不写入工程、编辑缓冲区、目标规则或模板；存储不可用时仍能在当前会话切换。切换更新 `html.lang` 和 Ant Design 内置控件语言，不重新挂载工作区。

`src/i18n/en.json` 保存英文 UI 文案，以中文原文作为键。组件显式使用 `t(source, values)`；命名占位符支持数量、路径和用户名称，不对插入值做翻译。未知键保留原文，便于逐项补齐，不能把未翻译的界面当作英文验收完成。新增文案需同时补充英文，并保持占位符一致。

工程名、文件名、路径、总线变量原名、配置值和源码不翻译。领域模型和文件字节不随语言改变；已保存状态按当前语言显示。源码编辑器通过 CodeMirror Compartment 更新可访问标签及内置短语，保持同一个编辑器实例、草稿及本地撤销历史。切换语言时只重建已打开的搜索面板，保留搜索词。

目前已接入工程总览、创建与导出页面、APP 启动表单、离线状态、源码编辑操作、工程打开/保存/复制、恢复草稿与归档预览，以及主站、模型、Hardware、资源、模板与扩展模块的界面文案。CodeMirror 内置搜索面板支持中文和英文。工程引用、IgH/ECM 主站、ENI 目录、APP 启动参数、Hardware/Binding、模块依赖、payload、模板与目标规则快照，以及 URDF 结构、几何、拓扑操作和控制链的结构化诊断已接入。IgH 从站、Hardware/Binding 和 URDF 结构修改的影响报告与复核提示已接入。归档错误、导入摘要和原生文件错误仍有未翻译内容，当前保留原文，因此中英文完整验收尚未完成。

领域核心使用 `src/core/project/messages.ts` 的 `m(key, values)` 创建消息，保留原中文 `message` 并附带可序列化的 `text` 模板。模板参数中的字符串和数字始终作为原始数据；只有显式嵌套的模板才继续翻译。核心不读取界面语言，也不导入 React 或英文词典。Worker 结果和已标注的异常保留这些模板，由界面的 `diagnosticText` / `errorText` 按当前语言渲染。切换已有诊断的语言不重跑校验或模型解析，也不改变规则代码、严重级别、文件定位或工程数据。复核提示的可选 `text` 元数据随工程保存；原中文 `message` 继续保留，兼容原有工程。读取提示时检查模板结构与原文一致性，无效、过深、展开超限或未知结构的元数据按原文显示，不改写归档内容。未标注的第三方异常及旧消息保留原文，不用字符串搜索替换猜测其中哪些内容属于用户配置。

验证包含：语言持久化、源码编辑器不重建及撤销/重做、搜索词保留、未应用草稿与文件字节往返、中文名称不翻译、1440/1024/390 宽度的英文布局、深色主题和侧栏文本完整性。配置页用例检查 IgH 64 位 SDO、ECM 原生标量、ENI 原始字节、Hardware 换算、URDF 预览姿态以及中文资源路径不受语言切换影响。Chrome、Playwright Firefox/WebKit 已执行相关用例。Pages 离线用例也检查断网切换及重载后的语言偏好，不依赖翻译服务或公网字典。变更确认用例覆盖打开弹窗期间切换语言、中文关节名保真、复核提示保存重开和撤销；同 UUID/revision 的工作区替换后，旧计划不能应用到新会话。
