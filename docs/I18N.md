# 界面语言

顶部语言菜单支持简体中文和 English，默认中文。偏好保存在当前浏览器/桌面 WebView 的 `rocos-locale`，不写入工程、编辑缓冲区、目标规则或模板；存储不可用时仍能在当前会话切换。切换更新 `html.lang` 和 Ant Design 内置控件语言，不重新挂载工作区。

`src/i18n/en.json` 保存英文 UI 文案，以中文原文作为键。组件显式使用 `t(source, values)`；命名占位符支持数量、路径和用户名称，不对插入值做翻译。未知键保留原文，便于逐项补齐，不能把未翻译的界面当作英文验收完成。新增文案需同时补充英文，并保持占位符一致。

工程名、文件名、路径、总线变量原名、配置值和源码不翻译。领域模型和文件字节不随语言改变；已保存状态按当前语言显示。源码编辑器通过 CodeMirror Compartment 更新可访问标签及内置短语，保持同一个编辑器实例、草稿及本地撤销历史。切换语言时只重建已打开的搜索面板，保留搜索词。

目前已接入工程总览、创建与导出页面、APP 启动表单、离线状态、源码编辑操作、工程打开/保存/复制、恢复草稿与归档预览，以及主站、模型、Hardware、资源、模板与扩展模块的界面文案。CodeMirror 内置搜索面板支持中文和英文。领域诊断、修改影响报告和原生错误说明仍有未翻译内容，当前保留原文，因此中英文完整验收尚未完成。

验证包含：语言持久化、源码编辑器不重建及撤销/重做、搜索词保留、未应用草稿与文件字节往返、中文名称不翻译、1440/1024/390 宽度的英文布局、深色主题和侧栏文本完整性。配置页用例检查 IgH 64 位 SDO、ECM 原生标量、ENI 原始字节、Hardware 换算、URDF 预览姿态以及中文资源路径不受语言切换影响。Chrome、Playwright Firefox/WebKit 已执行相关用例。Pages 离线用例也检查断网切换及重载后的语言偏好，不依赖翻译服务或公网字典。

```sh
npm test -- tests/i18n.test.ts
npm run test:ui -- tests/browser/i18n.spec.ts tests/browser/i18n-domain.spec.ts
npm run test:compat -- tests/browser/i18n.spec.ts tests/browser/i18n-domain.spec.ts
```
